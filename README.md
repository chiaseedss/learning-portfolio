# Learning Portfolio

An academic Computer Science portfolio by Tischia Ann R. Olivares, built with React, TypeScript and Vite. Warm yellow, cream backgrounds and simple responsive project cards.

Website destination: [Learning Portfolio](https://chiaseedss.github.io/learning-portfolio/) — deployment pending; this URL currently returns 404.

## Projects

Computer Vision includes Philippine Traffic Sign Detection, Fish Classification, Image Compression and Coin Image Preprocessing. The reviewed EduROOM team project appears under Software Development. Filters support Robotics, Artificial Intelligence & Machine Learning, and Other Coursework when approved projects become available. The five DIP problem sets are excluded.

Project pages explain objectives, methods, historical results, limitations, datasets and contributor credits. Restricted images and datasets are not included.

## Development

Requires Node.js 22.12+. Run `npm ci`, `npm run dev`, `npm run build` and `npm run validate`.

## GitHub Pages

Existing public repository: [chiaseedss/learning-portfolio](https://github.com/chiaseedss/learning-portfolio). Vite uses `/learning-portfolio/`; hash routes preserve project navigation. The workflow builds, validates and deploys only `dist/`. After publication approval, enable GitHub Actions as the Pages source. Nothing has been pushed or deployed during local preparation.
