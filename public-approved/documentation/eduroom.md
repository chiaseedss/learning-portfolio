# EduROOM classroom reservation system

Team-developed classroom reservation and scheduling application using Python, Flet, MySQL, WebSockets and Microsoft Azure.

## Methodology

- Python/Flet application with MySQL persistence and WebSocket updates.
- Azure App Service hosting and cloud infrastructure, as documented by the team.

## Results

- The published README documents reservation, approval, account-management and notification features. No quantitative performance benchmark is reported.

Historical project records; no new experiments were run.

## Limitations

- Historical deployment is described in the README; current live application availability has not been verified.
